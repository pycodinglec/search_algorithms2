# 탐색 실험실

[웹 시뮬레이터 열기](https://pycodinglec.github.io/search_algorithms2/)

네 탐색 알고리즘의 Python 코드와 실제 실행 과정을 함께 보는 학생용 실습 자료입니다.

## Python 파일

| 파일 | 선택 기준 | 종료 조건 | 줄 수 |
|---|---|---|---:|
| `깊이우선탐색.py` | 스택의 마지막 후보 | 후보가 빌 때 | 145 |
| `너비우선탐색.py` | 큐의 첫 후보 | 후보가 빌 때 | 145 |
| `최상우선탐색.py` | 도착점까지 거리 h | 도착점을 꺼낼 때 | 156 |
| `a_star.py` | 누적 비용 g + 거리 h | 도착점을 꺼낼 때 | 163 |


```sh
python3 a_star.py
python3 깊이우선탐색.py
python3 너비우선탐색.py
python3 최상우선탐색.py
```

프로젝트 폴더에서 실행하세요. `map4.txt`와 `cost4.txt`를 현재 작업 폴더에서 읽습니다. 두 파일은 같은 크기의 직사각형이어야 하며, 지도에 s와 d를 각각 하나씩 사용합니다. 지도에서 1은 벽, 비용은 한 칸당 1~9입니다. 입력 오류 검증은 원본의 범위를 유지합니다.

깊이·너비우선은 **비용을 반복 갱신하는 원본의 변형**입니다. 방문을 한 번만 하는 일반적인 DFS/BFS와 다릅니다. 더 싼 경로가 발견되면 같은 칸을 다시 탐색합니다. 모든 방식에서 출발 칸 비용도 포함합니다. 최상우선탐색은 최소 비용을 보장하지 않습니다.

## 웹에서 살펴보기

1. 알고리즘과 예제 지도를 고릅니다.
2. ‘후보 꺼내기’로 큰 흐름을 보고, ‘코드 한 줄’로 비교와 갱신을 따라갑니다.
3. 강조된 줄은 **다음에 실행할 줄**, 지도와 변수는 그 줄을 실행하기 **전** 상태입니다.
4. 이전·다음·슬라이더로 되감고, 자동 재생 속도를 바꿀 수 있습니다.
5. 칸을 눌러 g·h·진입 비용·직전 화살표를 확인합니다. ‘결과’와 ‘Python 출력 보기’에서 최종 경로를 확인합니다.

기본 화면은 입력 준비를 마친 탐색 함수에서 시작합니다. ‘처음’은 main의 파일 읽기부터 보여줍니다. 네 가지 예제와 비용 모드 두 가지를 제공합니다. 자유로운 코드 편집·실행 환경은 아닙니다.

화면에 표시하는 코드는 네 파일의 원문입니다. `tools/build_traces.py`가 CPython의 `sys.settrace`로 실제 실행 중 줄 번호, 호출 함수, 변수, 후보, 지도, 출력을 기록합니다. 웹은 이 기록을 재생하며 별도의 JavaScript 탐색 구현을 사용하지 않습니다. 예제와 비용 모드는 기록 생성 시 main 호출 전에 설정합니다. 함수 내부에 계측 코드를 추가하지 않습니다.

## 로컬 웹 실행과 검증

```sh
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

현재 기록은 CPython 3.14.7로 생성했습니다. 기록 재현 검사는 같은 버전을 사용하세요. Python 버전이 달라지면 줄 추적 방식이 달라질 수 있습니다.

```sh
python3 -B tools/build_traces.py
python3 -B -m unittest discover -s tests -v
node --check app.js
```

- 파일 입력부터 콘솔 출력까지 32개 실행과 웹 기록 비교
- `tools/browser_e2e.js`: Playwright CLI의 `run-code`에 전달하는 브라우저 검증 함수. 열려 있는 시뮬레이터에서 32개 조합, 이동·재생·코드 표시·모바일 화면을 검사합니다.

GitHub Pages는 main 브랜치의 루트에서 정적 파일을 게시합니다. 외부 라이브러리, 서버 계산, 로그인은 필요하지 않습니다.

## 복잡한 지도 8 × 12

예제 선택에서 ‘복잡한 지도 8 × 12’를 선택하세요. `examples/uploaded/map.txt`와 `cost.txt`는 제공된 파일을 그대로 보존합니다. 숫자 한 글자를 한 칸으로 읽는 형식이며, 비용 96칸은 모두 1~9입니다(0 이하·10 이상 없음). 출발점은 (4, 6), 도착점은 (5, 7)입니다. 네 알고리즘 모두 이 예제에서는 21칸, 총비용 81(출발 칸 포함)의 경로를 찾으며 비용 무시 모드에서는 21입니다.

데스크톱에서는 지도와 코드 사이의 경계선을 좌우로 드래그해 두 영역의 너비를 조절할 수 있습니다. 경계선에 키보드 초점을 맞춘 뒤 좌우 방향키로도 조절할 수 있습니다. 지도보다 영역이 좁으면 지도 내부를 좌우로 스크롤합니다. 처음 선택하면 출발점이 보이도록 가로 위치를 맞춥니다.
