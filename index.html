이 실험실의 실행 방식과 학습 범위
네 Python 파일을 CPython에서 실제 실행하며 기록한 줄 번호와 변수 상태를 재생합니다. 별도의 JavaScript 탐색 알고리즘으로 흉내 내지 않습니다. 입력 4개와 비용 모드 2개의 기록을 제공합니다. 코드를 자유롭게 편집·실행하는 Python 환경은 아닙니다.
첫 화면은 입력 읽기와 지도 구성이 끝난 ‘탐색’ 함수부터 보여줍니다. ‘처음’을 누르면 파일 읽기부터 결과 출력까지 살펴볼 수 있습니다. 코드의 기본 입력 설정은 그대로 표시되며, 예제와 비용 모드는 기록 생성 시 main 호출 전에 적용됩니다.
깊이·너비우선은 원본의 비용 반복 갱신 방식을 유지했습니다. 일반적인 방문 1회 방식과 다릅니다. h는 유클리드 거리이고, 위 → 오른쪽 → 아래 → 왼쪽 순으로 이웃을 확인합니다. 같은 우선순위에서는 기존 후보 순서를 유지합니다. 비용은 출발 칸을 포함합니다.
숫자는 화면에서 소수 셋째 자리까지 표시하며 실제 계산값은 반올림하지 않습니다. 줄 단위 재생에서는 함수 호출과 반환을 따라 같은 줄이 다시 보일 수 있습니다. 이전 반복에서 만든 지역 변수는 재할당될 때까지 남습니다.
